AI ESCAPE ROOM – THE MYSTERY OF THE LOCKED LIBRARY

1. Project Overview
The AI Escape Room is a Python-based interactive game in which players explore a mysterious locked library, discover hidden clues, solve puzzles, and escape by finding the correct codes.

The project uses Google Gemini API and Gradio to provide an interactive AI Game Master experience.

2. Technologies Used
- Python
- Jupyter Notebook
- Google Gemini API
- Gradio
- Python dictionaries and lists

3. Project Files
- Version_1_Escape_Room.ipynb – Original implementation of the escape room game.
- Version_2_Escape_Room.ipynb – Improved implementation with structured game state, inventory management, puzzle validation, error handling, and testing.
- Version 1 Screenshots – Screenshots showing Version 1 gameplay.
- Version 2 Screenshots – Screenshots showing Version 2 improvements and testing.
- AI_Escape_Room_Report.pdf – Complete project report.

4. How to Run the Project
1. Install Python and Jupyter Notebook.
2. Install the required Python packages used in the notebooks.
3. Configure your Google Gemini API key securely as required by the notebook.
4. Open the required Jupyter Notebook.
5. Run the notebook cells in order.
6. Launch the Gradio interface.
7. Open the local Gradio link in your web browser to play the game.

5. How to Play
1. Start the game and read the introduction.
2. Examine the wooden desk to find the first clue.
3. Examine the bookshelf to find the second clue.
4. Inspect the painting to discover the brass key.
5. Use the combination 2419 and the brass key to unlock the drawer.
6. Find the final exit code 7316 inside the drawer.
7. Enter the final code at the exit door to escape the library.

6. Version 2 Improvements
- Structured game state.
- Inventory management.
- Validated puzzle solutions.
- Secure four-digit exit code.
- Error handling.
- Automated testing.

7. Expected Result
After entering the correct final exit code, the player receives a successful escape message.
